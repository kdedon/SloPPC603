# Pure miss derivation verification

The strict `test-miss-derive` target passes **1,034 checks** (2026-09-23; `/tmp/ppc-sdr1-focused.log`). Five fixed literal vectors independently calculate effective page, PTE compare, and primary/secondary PTEG physical addresses from the 32-bit PowerPC Programming Environments Manual, §§2.3.4 and 7.6.1.3–7.6.1.4, Figures 7-28, 7-30 and 7-32. The vectors include zero, small and maximum HTABMASK values; a nonzero masked upper hash index; and all-one VSID/hash edges. Expected constants are embedded in the bench rather than generated by the DUT formula.

All 512 possible nine-bit masks are checked against the contiguous-low-ones rule. Invalid SR.T, reserved SDR1 bits, a misaligned table base, and a discontiguous mask must deassert validity and zero every derived output. SR.N alone must not invalidate derivation. Every valid PTEG address is 64-byte aligned.

The unit is combinational and side-effect-free. These checks do not claim automatic IMISS/DMISS, ICMP/DCMP or HASH1/HASH2 capture, exception entry, or software table search.
