# Source reference index

All files live in `references/source/` (next to `SKILL.md`) (bundle 2026-05-18; [`Template_MiSTer`](https://github.com/MiSTer-devel/Template_MiSTer/tree/f35083f3b40d24853abea4cd3f77caccbd71d5de), [`Main_MiSTer`](https://github.com/MiSTer-devel/Main_MiSTer/tree/136737b4bed4d5ba58216efdcede0094ae8e8041), [`MkDocs_MiSTer`](https://github.com/MiSTer-devel/MkDocs_MiSTer/tree/9033bd292fdcc98f30dfe47eed7d61371181454a), [`Hardware_MiSTer`](https://github.com/MiSTer-devel/Hardware_MiSTer/tree/bbd3619620056a0f44476e27f18b442b4f0a5952), [`Distribution_MiSTer`](https://github.com/MiSTer-devel/Distribution_MiSTer/tree/beb65fea786d3c897221724cfe797cc193965b27)). Do not modify them. Claims are tagged `[C]` contract, `[V]` convention, `[O]` observed, `[I]` inference. Each topic doc follows the same section layout: §1 purpose, §2 contract, §3 ports/signals, §4 sequencing/timing, §5 minimal pattern, §6 variations, §7 anti-patterns, §8 verification, §9 provenance.
