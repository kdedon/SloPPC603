## 1. Pipeline organization

**Structure.** Three instruction slots, advanced in lock-step, plus a one-word retention buffer:

| Slot | Registers | Role |
|---|---|---|
| bus | `mem_req/mem_addr/...` (registered outputs), `fetch_pc` | fetch in flight |
| `ahead_*` | instruction, pc, abort ([core:169-176](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L169-L176)) | a fetch that completed while execute owned the bus |
| `prefetch_*` | instruction, pc, abort, **`prefetch_ports`** (pre-decoded read indexes) | "decode" stage: combinational decode + RF read + forwarding |
| `decode_*` + `exec_*` | ~70 registered control/operand fields | execute: shifter + ALU + writeback |

Naming is shifted by one: `decode_valid/decode_pc` is really the *executing* instruction; `prefetch_*` is the one being decoded. The combinational `decode` block ([core:1766-2475](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1766-L2475)) reads `prefetch_instruction`, reads the register file, applies forwarding, and its `dec_*` outputs are captured into `exec_*` by the task `capture_prefetch_decode` ([core:1519-1585](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1519-L1585)). Execute (`execute_datapath`, [core:1111-1210](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1111-L1210)) works only from `exec_*` registers.

**PC+8 semantics** are synthesized, not a real pipelined PC: `visible_pc = decode_pc + (thumb ? 4 : 8)` ([core:455](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L455)) and for decode `decode_visible_pc = prefetch_pc + 8`, plus a `_p4` (PC+12) variant for register-shift and multiply forms which read R15 after an extra internal cycle ([core:465-466](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L465-L466), [612-628](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L612-L628), [673-684](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L673-L684)). Branch targets get their own adder in decode from `prefetch_pc + 8 + offset` ([core:2117-2118](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2117-L2118)), registered as `exec_branch_target`, so the ALU is not used for B/BL.

**Fetch address off the ALU path** ([core:447-454](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L447-L454)):
```systemverilog
// The add happens here, at use, from a register - not at issue
// time, where it sat in series after the ALU on every branch (the
// measured worst path ran shifter -> ALU -> align -> +step -> fetch_pc_next).
assign fetch_pc_next = fetch_pc + (thumb ? 32'd2 : 32'd4);
```
`issue_fetch` registers the *issued* address into `fetch_pc` ([core:1430](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1430)); the increment is done on the next use. Reset loads `fetch_pc <= VECTOR_RESET - 4` so the first sequential issue fetches the vector ([core:2580-2582](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2580-L2582)). Best practice: store "last issued" not "next", so a redirect only drives a mux, not mux+adder.

**Advance rule (lock-step).** RUN retires the executing instruction only when `decode_valid && prefetch_valid` ([core:2681](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2681)); otherwise the RUN branch just fills slots from the bus ([core:2938-2971](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2938-L2971)). Retirement goes through two tasks:
- `finish_sequential(resume_pc, post_control, refetch_seq)` ([core:1593-1642](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1593-L1642)): shifts prefetch→execute, ahead→prefetch (or bus→prefetch), issues the next sequential fetch, and checks interrupts using the *post-instruction* I/F bits.
- `finish_control(target, thumb, mask, mode)` ([core:1644-1671](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1644-L1671)): flushes `decode/prefetch/ahead` valid bits and issues the target fetch non-sequential.

Branch penalty is therefore the architectural 2S+N (two refill fetches). Anything that changes T, mode, or does a control-byte MSR/SPSR restore also goes through `finish_control`; this invariant is exploited heavily (see §2).

**Multi-cycle instructions: explicit FSM, not microcode.** `core_state_e {RUN, MEM_ACCESS, SWP_READ, SWP_WRITE, BLOCK_ACCESS, MUL_WAIT, MEM_DONE, HALTED}` ([core:78-87](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L78-L87)). On entry RUN latches a per-class *transfer descriptor* (`data_*`, `swp_*`, `block_*`, `mul_*` register groups, [core:205-275](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L205-L275)) plus a `*_resume_pc`, then the side state runs purely from those registers. Before leaving RUN every multi-cycle class calls `retain_completed_fetch()` ([core:1506-1517](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1506-L1517)) so a fetch that completes on the same edge is parked in `ahead_*` instead of being lost when the bus is re-used for data.

- **Trailing internal cycle** (the manual's "+I") is modelled by a shared `MEM_DONE` state entered via `start_internal_completion(resume_pc, control_flow)` ([core:1491-1504](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1491-L1504), [3015-3021](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3015-L3021)). Loads, LDM, SWP and (with MUL_RETIRE_STAGE) multiplies all converge there. One convergence state for "retire from registers next cycle" is a clean pattern.
- **Register-shift extra cycle**: `exec_internal_cycle` + `internal_cycle_pending` flag spends one bus-idle cycle inside RUN ([core:2699-2708](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2699-L2708)).
- **Undefined** spends a coprocessor-wait I cycle ([core:2469-2474](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2469-L2474)).
- **Stores vs loads** resume differently (store has no trailing I; [core:2986-3010](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2986-L3010)).

Evaluation: the FSM is readable for ARM7's small set of multi-cycle ops. The lock-step advance (execute cannot retire until the next instruction is decoded) is simple but couples execute to fetch latency — acceptable for a zero-wait-state ARM7, wrong for a 603e with an instruction queue.

## 2. Decode

- **Thumb is decoded natively onto the ARM control vocabulary**, not translated to a 32-bit ARM encoding ([core:89-90](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L89-L90): "Thumb forms are decoded onto the same set so one ALU serves both"). Both branches of the decode `if` (ARM [core:1870-2128](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1870-L2128), Thumb [core:2129-2467](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2129-L2467)) write the same `dec_*` fields: ALU opcode, operand *source names*, shift type/amount, flag mask, memory descriptor. This is equivalent to a "decoded uop struct" approach.
- **Operand-source indirection** ([core:108-125](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L108-L125), [1694-1739](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1694-L1739)): decode does not mux register values; it emits a 4-bit `dec_op1_sel`/`dec_op2_sel`/`dec_amount_sel` naming a source (`SRC_ARM_RN`, `SRC_T_R3`, `SRC_SP`, `SRC_IMM`...). A separate flat `operand_select` block acts on the name:
  ```systemverilog
  // Decode names an operand source; this mux acts on the name. Keeping it
  // flat and outside the decode chain is what holds the register file, the
  // forwarding path and the shifter two levels apart.
  ```
  Clear best practice: the long if/else priority chain of decode only produces *small control codes*, and the 32-bit data only goes through one flat case mux + one forward mux. Otherwise the synthesizer builds the data mux in the shape of the priority chain.
- **Pre-decode at capture time** ([core:641-666](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L641-L666), [1619-1620](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1619-L1620), [2957](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2957)): `port_indexes()` extracts the four RF read indexes (ARM Rn/Rd/Rs/Rm or Thumb fields incl. hi-register bit) when the word enters the prefetch slot and registers them in `prefetch_ports`. So RF reads launch from flops, not from an ARM/Thumb field mux. Directly analogous to I-cache predecode bits.
- **Mode/T from the registered CPSR, deliberately** ([core:456-464](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L456-L464)): `decode_thumb = thumb` (registered), not forwarded, because anything that changes T/mode flushes. "Reading `cpsr` here takes the whole ARM/Thumb split of the decode chain ... off the ALU's forwarding cone." The same argument is used for the MSR user-mode mask ([core:1915-1917](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1915-L1917)). Technique: establish a "serializing instructions flush" invariant, then decode can use architected (non-forwarded) state for mode bits.
- **Condition evaluation as a precomputed vector** ([core:1741-1764](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1741-L1764)): all 16 conditions computed from the forwarded flags once, then `dec_condition = decode_thumb || cond_pass_vec[instruction[31:28]]` ([core:1791](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1791)). The ALU flag result reaches `exec_condition` through one 16:1 select instead of entering decode's priority chain. (Note: `condition_pass()` in [pkg:82-111](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_pkg.sv#L82-L111) is now dead code.)
- **Shared immediate rotator**: `arm_imm_ror` computed once for MSR and DP immediate forms ([core:1782-1786](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1782-L1786)).
- **Normalise encodings to one form**: immediate-shift special cases (LSR/ASR #0 = #32, ROR #0 = RRX) are converted to the register-amount form so one shifter serves both ([core:1675-1692](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1675-L1692)).
- Decode block has full defaults at the top ([core:1790-1865](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1790-L1865)) — no latches.
- **Weakness**: decode is one 700-line `if/else if` chain with masked compares (e.g. [core:1881](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1881), [1903](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1903), [1930](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1930)). Order-dependent, and its control outputs (`dec_kind`, `dec_write_reg`...) still form a deep priority mux. It works for ARM's ~15 formats; for PowerPC (primary opcode + XO) a `case (opcd)` with nested `case (xo)` is flatter.

## 3. Register file and banking

- **Flat physical file, mode changes only the index map** ([core:142-153](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L142-L153), [474-495](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L474-L495)):
  ```systemverilog
  // One flat physical register file. A mode switch changes only the
  // index mapping - no data ever moves between banks, which deletes the
  // whole save/reload selector fabric the area histogram measured at a
  // third of the core. Layout: 0-7 R0-R7; 8-14 the user/system R8-R14
  // ...; 15-21 FIQ R8-R14; 22-29 the R13/R14 pairs of IRQ, SVC, ABT, UND.
  logic [31:0] rf [0:29];
  ```
  `rf_index(index, mode)` maps logical→physical from registered inputs only ("ready long before the read data is needed", [core:471-473](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L471-L473)). ## 4. Barrel shifter / ALU / flags

- **One rotator for all four shift types** ([pkg:123-185](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_pkg.sv#L123-L185)): LSL n = ROR (32-n) with low bits masked, LSR = ROR n with high bits masked, ASR = ROR n with high bits sign-filled, ROR = rotate. - **Carry-in fused into the adder chain** ([core:1095-1105](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1095-L1105)):
  ```systemverilog
  // Bias bit zero so Quartus uses one carry chain for all three inputs.
  add_with_carry = 33'(({1'b0, lhs, 1'b1} + {1'b0, rhs, carry_in}) >> 1);
  ```
  Classic trick; ensures ADC/SBC/RSC do not get a second adder for `+cin`. Directly applicable to `adde/subfe/addme/addze`.
- **Weakness — ALU not written as one adder**: each of SUB, RSB, ADD/CMN, ADC, SBC, RSC, CMP has its own `arithmetic = ...` expression inside `case (exec_dp_opcode)` ([core:1133-1194](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1133-L1194)). Quartus may build several 33-bit adders + a wide mux; on the critical loop (forward → operand mux → shifter → ALU) that is costly. Better: `a' = inv_a ? ~a : a; b' = inv_b ? ~b : b; sum = a' + b' + cin` with `inv_a/inv_b/cin_sel` decoded in the previous stage. The core did not do this even though the ALU is on its measured worst path.
- **Flags**: N/Z/C/V computed in execute, merged with a decoded mask `exec_flag_mask` (`dp_post_cpsr = (cpsr & ~mask) | (flags & mask)`, [core:1196-1209](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1196-L1209)). - Z = `dp_result == 0` on the loop ([core:1198](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1198)); V computed per op from sign bits.

## 6. Memory interface

- **Internal bus is a simple registered request / combinational ready** ([core:53-65](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L53-L65)): `mem_req, mem_addr, mem_write, mem_wdata, mem_size, mem_wstrb, mem_seq, mem_fetch, mem_privileged, mem_lock` are all registered outputs driven via tasks (`issue_fetch`, [core:1411-1432](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1411-L1432)) or FSM arms. - **Loads**: `load_lane()` does ARM7's misaligned-word rotation, byte/half extract and sign extension, including the quirky misaligned LDRH/LDRSH ([core:1299-1330](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1299-L1330)). Stores replicate lanes (`store_lanes`, byte to all four lanes) and generate strobes (`store_strobes`) ([core:1332-1352](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1332-L1352)).
- **Pin wrapper** ([`arm7tdmi_pin_wrapper.sv`](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_pin_wrapper.sv)) is a pure adapter: `nMREQ = !mem_req`, `SEQ = mem_seq`, `nRW = mem_write`, `MAS = mem_size`, `nWAIT → mem_ready`, `ABORT → mem_abort`, `nOPC = !mem_fetch`, `TBIT` latched from the last fetch size ([wrapper:47-63](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_pin_wrapper.sv#L47-L63)). Its header ([wrapper:4-6](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_pin_wrapper.sv#L4-L6)) is honest: "a protocol-level pin contract, not electrical or half-cycle compatibility". Note the real ARM7 bus is *pipelined* (address/nMREQ/SEQ valid the cycle before data); the wrapper does not model that. Lesson: keep the core on a simple internal req/ready bus and put bus-protocol pipelining (60x address/data tenure) in an adapter.
- **Integration pitfall, documented at length** ([SDC:84-104](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L84-L104); [`rtl/arm_mapper_memory.sv:623-627`](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm_mapper_memory.sv#L623-L627)): the memory system answers `mem_ready`/`mem_rdata` combinationally from the address decode, and the core forwards `data_loaded_value = load_lane(mem_rdata, ...)` straight into the operand forwarding network ([core:749](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L749), [995-998](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L995-L998)) and captures `mem_rdata` into prefetch/`port_indexes()` ([core:2956-2957](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2956-L2957)). So external decode → load lane → forward mux → operand mux → exec register is one cycle. That is the dominant failing path (-2.5 ns). **Do not let a raw memory response enter the bypass network in the same cycle.** Register the response (or give load data its own writeback cycle) and forward it one cycle later.

## 7. Exceptions / interrupts / modes

- **Interrupts sampled only at retirement**, using the post-instruction mask bits: `finish_sequential` passes `post_control = exec_effective_post_cpsr[7:0]` so an MSR that sets I/F takes effect for the very next boundary ([core:1610-1612](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1610-L1612), [2749-2750](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2749-L2750)). If an interrupt/halt is pending, `request_boundary` ([core:1462-1486](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1462-L1486)) flushes all slots, records `boundary_pc` and a `boundary_event` with priority **halt > FIQ > IRQ**, and drops the bus if it is free. RUN then waits for the bus to drain and calls `enter_exception` ([core:2658-2680](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2658-L2680)). A two-step "request → drain → enter" is simple and precise.
- **`enter_exception`** ([core:1434-1460](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1434-L1460)) does everything in one edge: new CPSR (I=1, F=1 for FIQ, T=0, mode), SPSR of the target mode ← old CPSR, `rf[rf_index(14, target_mode)] <= link` (no bank copy thanks to the flat file), flush, fetch vector (ARM state, non-seq).
- **Prefetch abort travels with the word** ([core:172-178](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L172-L178), [1511](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1511), [1622](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1622), [2682-2698](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2682-L2698)): `ahead_abort → prefetch_abort → exec_abort`; taken only when the word reaches execute, regardless of condition; a branch that discards the word discards the abort. This is exactly the precise-exception model a 603e needs for ISI (tag the fetch-buffer entry, raise at completion).
- **Data abort** from MEM_ACCESS/SWP/BLOCK enters DABT with LR = PC+8 ([core:2976-2978](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2976-L2978), [3025-3026](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3025-L3026), [3062-3064](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3062-L3064)). Base writeback is suppressed on abort (write enables are not set), i.e. a base-restored model; the real ARM7TDMI uses the base-updated model — possible divergence, untested in this system (aborts only come from bad-address decode, [`arm_mapper_memory.sv:626`](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm_mapper_memory.sv#L626)). LDM also stops at the aborting beat instead of finishing the transfers with writes suppressed (timing-only difference).
- **Mode validation**: CPSR writes with an invalid mode are dropped (`mode_valid`, [core:2728](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2728), [3265](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3265)); MSR forces CPSR bit 4 to 1 ([core:1918-1923](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1918-L1923), "oracle-verified").

**SDC philosophy** ([`arm7tdmi.sdc`](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc)):
- **No multicycle paths in the core** ([SDC:31-71](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L31-L71)): "Every state that looks multi-cycle from the outside re-launches from registers on each clk_arm edge ... Important warning: FSM-held registers are often read on the next edge in the degenerate case; a multicycle there is a silent hardware bug.
- **False path for quasi-static configuration** into `clk_arm` ([SDC:106-160](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L106-L160), [193-217](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L193-L217)), scoped `-to $arm7_clk_arm` (the clock) so the same registers stay timed elsewhere. Rationale for false path over multicycle: "there is no interval to derive" ([SDC:195-203](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L195-L203)).

- **Robust clock lookup**: a Tcl proc tries both altera_pll naming schemes (`general[n]` vs `cyclonev_pll|counter[n]`) and emits `critical_warning` when the PLL exists but the clock is not found, because a previous single-pattern guard silently became a no-op after an IP retype ([SDC:162-180](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L162-L180)). Also warns when the target registers are missing ([SDC:210-214](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L210-L214)). Best practice for any SDC exception: fail loudly when the collection is empty.
- **CDC mailboxes deliberately left timed** ([SDC:218-224](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L218-L224)): a false path to `*_sync1` would let the toggle arrive before the held payload, inverting the handshake ordering.

## 11. Other techniques worth extracting

- **Transfer descriptors**: on entering a multi-cycle op, snapshot everything the side-FSM needs (`data_*`, `block_*`, `swp_*`, `mul_*`, resume PC) into dedicated registers; the side-FSM never looks at decode/exec again, so the pipeline registers can be reused for the next instruction. Same concept as a load/store queue entry.
- **Resume PC captured per op** (`data_resume_pc`, `block_resume_pc`...), and a common `MEM_DONE` retire state parameterised by `(resume_pc, control_flow)`.
- **Interrupt/halt as a pseudo-instruction boundary event** with a shared drain path — halting for debug and interrupt entry share `request_boundary`.
- **Parameterised accuracy switch** with the measured cost written in the parameter doc and at the instantiation ([core:18-41](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L18-L41), [host:46-58](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm_host.sv#L46-L58)).
- **Single-writer register-file port funnel + late-enable** (§3) and **forward-valid without handshake qualifiers** (§3) are the two most general-purpose tricks in the file.

## Top transferable lessons for a 603e core (ranked)

1. **Rename-by-index, never copy data.** *Why*: the GBA-derived bank save/restore fabric was ~1/3 of the core; a flat file with a registered-input index map removed it and made mode switch/exception entry free. *Evidence*: [core:142-153](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L142-L153), [474-495](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L474-L495), [1450](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1450), [2515-2516](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2515-L2516). *603e*: the same principle is the rename model — GPR/FPR architected names map to physical slots (arch file + rename buffers) via a map computed from registered state; completion updates the map/commits, never moves operands. Also use it for shadow/SPR banks (SRR0/1, SPRG) if any are banked.

2. **Separate "which" from "whether" on write ports.** *Why*: selecting RF write address/data from stable state and letting the late handshake (`mem_ready`) drive only the enable took the bus off the RF decode/data mux. *Evidence*: [core:2479-2546](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2479-L2546), [3285-3288](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3285-L3288). *603e*: funnel all GPR/rename-buffer writes into N fixed result buses (one per unit: IU, LSU, SRU, FPU); the cache-hit/ready signal gates only the write enable and the ROB "finished" bit.

3. **Forward tags compare against constant instruction fields in parallel with RF read; the hit travels with the operand; no handshake qualifiers on forward-valid.** *Why*: leaves one 3:1 mux on the loop; a forward computed on a non-completing cycle is simply not captured. *Evidence*: [core:511-542](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L511-L542), [970-977](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L970-L977), [1697-1739](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1697-L1739). *603e*: rename-tag match in dispatch/reservation stations should compare against predecoded source tags registered in the IQ, and result-bus valid should not include downstream stall/ready terms.

4. **Decode emits small control codes (operand-source names); one flat mux acts on them.** *Why*: prevents the synthesizer from building the 32-bit data mux in the shape of decode's priority chain. *Evidence*: [core:108-125](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L108-L125), [1694-1739](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1694-L1739). *603e*: decode to a packed uop struct with `src_a_sel/src_b_sel/imm_kind`, and select register vs immediate vs SPR in a flat case in the issue stage.

5. **Predecode at fetch-buffer capture.** *Why*: RF read ports launch from flops instead of from field muxes. *Evidence*: `port_indexes()` [core:641-666](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L641-L666), [1619-1620](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1619-L1620), [2957](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2957). *603e*: compute rA/rB/rS/rD indexes, unit class and "serializing" bits when words enter the 6-entry instruction queue (or store them as I-cache predecode bits), so dual dispatch reads them from registers.

6. **Never let a raw memory response feed the bypass network combinationally.** *Why*: external decode → load lane → forward → operand mux in one cycle is this design's failing path (-2.5 ns). *Evidence*: [core:749](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L749), [995-998](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L995-L998), [2956-2957](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2956-L2957); [SDC:84-104](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L84-L104); [Atari7800.sdc:134](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/Atari7800.sdc#L134); [arm_mapper_memory.sv:623-627](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm_mapper_memory.sv#L623-L627). *603e*: D-cache data → align/sign-extend → register → result bus (2-cycle load-use like the real 603e); I-cache data → register → instruction queue.

7. **Store the last issued fetch address, increment at use.** *Why*: a redirect then drives only a mux; removed ALU→align→+4→fetch_pc from the worst path. *Evidence*: [core:447-454](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L447-L454), [1430](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1430), [2580-2582](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2580-L2582). *603e*: fetch PC register holds the issued address; sequential next = `pc + 8/16` computed from the register; branch redirect (BPU/branch folding) muxes in a precomputed target.

8. **Serializing ops flush → decode may use architected (registered) mode state.** *Why*: T/mode bits never needed forwarding into decode, removing the ARM/Thumb split from the ALU's forwarding cone. *Evidence*: [core:456-464](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L456-L464), [1915-1917](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1915-L1917), [2735-2747](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2735-L2747). *603e*: make `mtmsr`, `rfi`, `isync`, `sc`, `mtspr` to context-changing SPRs execution-serializing + refetch; decode/translate can then read MSR[PR/IR/DR/FP] from the committed register.

9. **Precompute all condition outcomes as a vector and index it.** *Why*: forwarded flags reach the condition result through one 16:1 select. *Evidence*: [core:1741-1764](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1741-L1764), [1791](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1791), [2432](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2432). *603e*: for `bc` with BO/BI, compute a 32-bit "CR bit true" vector from the (renamed/forwarded) CR and select by BI; evaluate CTR==0 (pre-decrement) in parallel.

10. **Priority-list walk with registered rest mask + lowest-set-bit isolate + OR-tree encoder, one step ahead.** *Why*: removed a priority chain from the shifter-launch path. *Evidence*: [core:222-226](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L222-L226), [1354-1360](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1354-L1360), [2800-2809](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2800-L2809), [3074-3079](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3074-L3079). *603e*: `lmw/stmw`, `lswi/stswi` sequencing, and any free-list / oldest-ready picker (rename buffer allocation, completion-queue retire of up to 2 entries).

11. **One rotator + per-bit masks for all shifts.** *Why*: a third of the area of four shifters and two LUT levels after the rotator. *Evidence*: [pkg:123-185](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_pkg.sv#L123-L185). *603e*: implement `rlwinm/rlwnm/rlwimi/slw/srw/sraw/srawi` as one 32-bit rotator + mask generator (MB/ME thermometer compare) + sign fill — exactly the PowerPC semantic model; CA for `sraw` from "any 1 shifted out & sign".

12. **Fuse carry-in into one adder chain.** *Why*: avoids a second adder for `+cin`. *Evidence*: [core:1095-1105](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1095-L1105). *603e*: `adde/subfe/addze/addme/subfic`. And do better than this core: build the IU as a single adder with decoded operand inversion + cin select (the ARM ALU here instantiates an adder per opcode arm, [core:1133-1194](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1133-L1194)).

13. **Iterative multiplier with corrections hoisted to entry, retire from registers, early-out by significant bytes.** *Why*: kept the multiplier off the forwarding loop (-3.84 ns when it was on); cycle counts match the chip. *Evidence*: [core:767-795](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L767-L795), [1228-1293](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1228-L1293), [947-952](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L947-L952). *603e*: `mullw/mulhw/mulhwu/mulli` on the IU with the 603e's data-dependent latency (early exit on 16-bit multiplier); use a registered DSP product and put the result on the result bus only from a register; `divw` as an iterative unit with the same "retire from registers" rule.

14. **Pre-register and replicate high-fanout completion decisions.** *Why*: one retire flag had "thousands of loads"; compute it one edge early from a down-counter and replicate per consumer group with `dont_merge maxfan`. *Evidence*: [core:243-253](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L243-L253), [2868-2870](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2868-L2870), [3154-3162](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3154-L3162). *603e*: stall/flush/"completion this cycle"/mispredict-flush signals — generate registered copies per consumer (fetch, dispatch, each unit, rename map).

15. **Exceptions tagged on the instruction, raised at the boundary; interrupts sampled at retire with post-instruction mask.** *Why*: precise, and a discarded word discards its fault. *Evidence*: [core:172-178](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L172-L178), [2682-2698](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2682-L2698), [1610-1612](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1610-L1612), [1462-1486](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1462-L1486). *603e*: carry ISI/ITLB-miss/alignment/DSI status in the IQ/completion-queue entry; take them when the entry is oldest; sample `EE` from the committed MSR after each completion group; halt/debug share the same drain path.

16. **Multi-cycle ops snapshot a descriptor and converge on one "retire from registers" state.** *Why*: pipeline registers free up; one place handles the trailing internal cycle and PC redirect. *Evidence*: [core:205-275](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L205-L275), [1491-1504](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1491-L1504), [3015-3021](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3015-L3021). *603e*: LSU miss/reload, `lmw`, `dcbz`, TLB-miss tablewalk (the 603e does software tablewalk via exceptions — still needs descriptor capture of the faulting EA/SRR), cache-line fill.

17. **SDC: no multicycles on FSM-held registers; false paths only for truly quasi-static config, scoped `-to <clock>`, by instance, with loud guards.** *Why*: degenerate cases (1-reg LDM, m=1 multiply) read "multi-cycle" registers the next edge; fitter-retimed names cannot be matched by register name; a stale pattern silently turns an exception into a no-op. *Evidence*: [SDC:31-71](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L31-L71), [128-134](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L128-L134), [162-217](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi.sdc#L162-L217). *603e*: keep the core single-cycle-constrained; any exception file must `post_message -type critical_warning` on empty collections.

18. **Architectural state port + retire trace from day one; pin UNPREDICTABLE behaviour to a reference; parameterise any accuracy trade.** *Why*: enables SingleStepTests-style per-instruction vectors and cycle-count checks; this repo's harness is not committed, so it is not reproducible. *Evidence*: [core:69-75](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L69-L75), [3212-3281](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L3212-L3281), [179-187](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L179-L187), [1600-1608](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1600-L1608), [18-41](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L18-L41); [host:46-58](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm_host.sv#L46-L58). *603e*: a halted-state port covering GPR/FPR/CR/XER/LR/CTR/MSR/SRR/SPRG/BAT/SR, a retire trace per completed instruction (both completion slots), and an in-repo harness driven by a reference model (e.g. a Dolphin/PearPC-derived stepper).

19. **Use packed structs for decode→execute payloads (the anti-lesson here).** *Why*: 140 loose signals and a field-by-field copy task are this file's biggest maintenance cost. *Evidence*: [core:277-407](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L277-L407), [1519-1585](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L1519-L1585). *603e*: `typedef struct packed { ... } uop_t;` for IQ entries, reservation stations and completion-queue entries; one assignment per stage transfer.

20. **Do not reset datapath arrays.** *Why*: the RF reset loop ([core:2551-2552](https://github.com/MiSTer-devel/Atari7800_MiSTer/blob/0dc8ad2e3ff724af57ba84c913e035a4c97733e8/rtl/arm7tdmi/arm7tdmi_core.sv#L2551-L2552)) forces 960 flops and adds reset fan-out. *603e*: GPR/FPR/rename files must go into MLAB/M10K (replicated for read ports); reset only valid bits, map tables and control state.
